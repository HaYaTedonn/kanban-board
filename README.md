# カンバンボード（タスク/案件管理）デモ

チームのタスク・案件を見える化する **カンバンボード** のデモです。
ドラッグ&ドロップでカードを動かしながら、進捗を管理できます。

**ライブデモ:** https://hayatedonn.github.io/kanban-board/

## 主な機能
- 列（未着手 / 進行中 / レビュー / 完了）。列の **追加・名称変更・削除**
- カード：タイトル・説明・期限・担当者・ラベル色・優先度（高/中/低）
- **ドラッグ&ドロップ**で列間・列内を並べ替え（挿入位置のプレビュー付き）
- カードの追加・編集・削除（モーダル）
- 全体の進捗バー（完了率）・各列のカード件数
- キーワード検索・担当者での絞り込み
- 期限切れカードの色分け表示

## 技術ポイント
- **ライブラリ不使用**のネイティブ HTML5 Drag and Drop API でD&Dを実装
- localStorage によるデータ永続化（リロードしても状態を維持）
- バニラ JavaScript + CSS、外部CDNなし／レスポンシブ

## ファイル構成
- `index.html` … 単一ファイルで完結（CSS/JS内包）

## 補足
表示データは架空のサンプルです。実装版では、複数ユーザーのリアルタイム同期、通知、サーバー側DBなどに拡張できます。
